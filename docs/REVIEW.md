# Review: improve reasoning, proof and case replay

CaseZero previously accepted only one evidence recipe for each conclusion, guided players back to those same cards and erased a submitted investigation immediately on replay. Phase 4 preserves all three mysteries while accepting three logically supported alternatives in The Quiet Hour and Dead Air, recording the actual proof used, and guiding players along an attainable route. After the Flood keeps its causal reconstruction and gains specific feedback on unsupported explanations.

Evidence-gated interview checks distinguish recorded claims from corroboration, conflicts and limited-scope alibis. The board and notebook show actual supporting records. End review explains which account dimensions fit the established proof; successful players can inspect overlooked search points or reopen the case. Replay now requires confirmation. Per-tab case preferences prevent refresh from opening another tab's investigation, and section navigation restores heading focus and top scroll position.

Version 3 migrates valid v1/v2 saves and endings using their original canonical requirements. Save keys and backup format stay stable; malformed older states cannot exploit newly accepted alternatives. Content checks reject insufficient, ambiguous and circular proofs. No dependencies, external services, fourth mystery, score or deployment were added.

Validation passed: typecheck, lint, production build, clean install, 116 unit/component tests and all 128 production browser tests (32 each in Firefox, WebKit, desktop Chromium and mobile Chromium emulation). Zero axe violations were found on audited screens. Exact verification scope and browser setup are recorded in [VERIFICATION.md](VERIFICATION.md); milestone evidence is in [PLAN.md](PLAN.md). [PLAYTESTING.md](PLAYTESTING.md) provides a practical first-time/mobile/accessibility session guide and a blank, voluntary feedback template. No human testing results are claimed. Prioritize those sessions and actual devices/screen readers before expanding systems further.
